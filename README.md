# 装箱计算器 | Carton · Pallet · Container Loading Calculator

**[English version →](README.en.md)**

一个纯本地、单文件、无服务器的装箱计算工具。苹果风格简洁界面，三步串联完成从彩盒到货柜的整条装载链路计算。

> 🔒 **隐私声明**：所有计算均在浏览器本地完成（原生 JS），不上传任何数据、不经过任何服务器或 API，可断网使用。

🔗 在线使用：https://krstic-c.github.io/carton-calculator/

---

## 项目定位

外贸/工厂日常报价与装箱方案设计中，"彩盒尺寸 → 外箱规格 → 卡板码放 → 货柜利用率"是一条高频重复的计算链路，人工核算容易出错且耗时。本工具把这条链路做成一个可视化、实时联动的单页计算器，输入源头尺寸，逐步得到每一环的推荐方案与利用率。

参考形态：单文件 HTML 工具，可部署到 GitHub Pages 在线使用，也可以离线双击 `index.html` 直接打开。

## 技术要求

- **纯前端**：HTML + CSS + 原生 JavaScript，无构建步骤、无框架依赖
- **零网络依赖**：不加载任何外部字体/脚本/资源，中文用系统苹方（PingFang SC），彻底离线可用
- **部署方式**：单文件，可部署 GitHub Pages，也可本地直接打开 `index.html` 离线使用
- **兼容性**：Chrome / Edge / Safari 最新版即可

## 核心功能

### STEP 01　彩盒尺寸 → 推荐外箱尺寸
- [x] 输入彩盒长宽高、单个重量、每箱数量、整体放尺余量
- [x] 自动遍历彩盒的排列组合与摆放方向，按体积利用率排序给出候选外箱方案
- [x] 等轴测（Isometric）图纸预览排列方式，工程制图风格标注

### STEP 02　外箱 → 卡板装载利用率
- [x] 卡板规格预设：1200×1000 亚洲标准 / 1100×1100 日标 / 1067×1067 美标 CP1 / 1200×800 欧标 EUR，支持自定义
- [x] 最大堆高、最大载重限制（留空则不限）
- [x] 自动计算每层箱数、可堆层数、总箱数与体积/面积利用率

### STEP 03　卡板 / 外箱 → 货柜装载利用率
- [x] 货柜规格预设：20GP / 40GP / 40HQ / 45HQ（内尺寸），支持自定义
- [x] 两种装载模式：**按卡板装载**（沿用 STEP 02 的卡板方案）/ **地板散装**（无卡板，外箱直接铺装）
- [x] 自动计算装载数量与空间利用率

### 汇总链路 Summary Chain
- [x] 三步计算结果自动串联展示，一屏看完从彩盒到货柜的完整装载方案

### 易用性
- [x] 实时联动：修改任意输入，下游结果与图纸即时刷新，无需手动点击"计算"
- [x] 苹果风格简洁界面（圆角卡片、系统字体、克制的单一强调色），支持深色模式自动跟随系统
- [x] 卡板/货柜规格支持存为常用预设、结果可一键复制文字摘要、支持打印/导出 PDF

## 界面结构

三个 STEP 卡片自上而下排列（长/宽/高/重量 → 卡板规格 → 货柜规格），每个 STEP 左侧输入、右侧结果统计卡片 + 等轴视图，底部汇总链路 Summary Chain 串联展示整条链路的关键数字。
